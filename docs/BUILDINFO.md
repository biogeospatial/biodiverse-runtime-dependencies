# BUILDINFO.txt

## Purpose

`BUILDINFO.txt` records information about the environment and dependency versions used to generate a runtime dependency build.

The file provides traceability between:

```text
Release Metadata
        ↓
Release
        ↓
Artifact
        ↓
BUILDINFO.txt
```

## Requirements

Runtime dependency build workflows shall generate BUILDINFO.txt.

The file shall be included in:

- CI artifacts
- Release artifacts

BUILDINFO.txt shall be generated by:

- macos-runtime.yml
- windows-runtime.yml
- linux-runtime.yml

when those workflows produce runtime dependency artifacts.
