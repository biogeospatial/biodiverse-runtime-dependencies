# Runtime Dependency Release v0.1.0

## Release Purpose

Initial cross-platform runtime dependency framework release.

## Changes

- Added runtime dependency release framework.
- Added BUILDINFO generation.
- Added Linux, macOS and Windows runtime workflows.
- Added runtime baseline documentation.
- Added Brewfile-based macOS dependency management.
- Added cross-platform Perl runtime support.
- Added configured Windows Strawberry Perl runtime support.

## Dependency Changes

### Windows

- Strawberry Perl 5.38.4.1
- Perl 5.38.4

### macOS

- Perl 5.38.4

### Linux

- Perl 5.38.4
